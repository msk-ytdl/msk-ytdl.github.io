# MSK VidMate — Official Download Website

> Live website: [https://msk-ytdl.github.io](https://msk-ytdl.github.io)

This repository contains the official landing page and distribution website for **MSK VidMate** — the modern, open-source YouTube Video and Audio Downloader for Android and Windows.

## Features
- 🚀 **100% Static & Blazing Fast**: Pure Vanilla HTML5, CSS3, and modern JavaScript.
- 📱 **Mobile & Desktop Responsive**: Beautiful dark theme design matching VidMate aesthetics.
- ⚡ **Direct Downloads**: Direct 1-tap download links for Android APK (`v1.0.0`) and Windows Standalone Package.
- 📖 **Comprehensive Guides**: Step-by-step installation instructions for Android and Windows.
- 🔒 **Zero Trackers & Zero Ads**: Clean and privacy-respecting.
